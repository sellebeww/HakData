# Ringkasan Proyek
Hak Data: workflow terstruktur untuk menggunakan hak subjek data (UU 27/2022). Monorepo: `apps/web` (Next.js), `apps/api` (NestJS + GraphQL + Prisma). Infrastruktur dev: Postgres dan RabbitMQ via docker-compose.
Prioritas keputusan: nilai produk > akurasi hukum > keamanan > fungsi > UX > maintainability > visual. Identitas visual diturunkan dari logo: navy gelap, gradien cyan→biru→ungu, lubang kunci pada "D".
Status: MVP berfungsi dan teruji lokal; **belum** ditinjau ahli hukum, belum diuji pengguna nyata, belum dideploy.
